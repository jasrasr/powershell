# Shared project memory
The .ai folder lives only at the repository root (the folder containing .git), never in subfolders. Do not create .ai folders in subfolders.
Even when working in a subfolder, read the root .ai/PROJECT.md, .ai/DECISIONS.md and .ai/HANDOFF.md before changing code.
Update the root .ai/HANDOFF.md after meaningful work, recording verified results and next actions.
Update .ai/DECISIONS.md only for durable architectural or product decisions.
Do not store secrets, customer data, credentials, raw transcripts, or proprietary content.
Never commit or push automatically as part of a handoff. Respect organization policies.
